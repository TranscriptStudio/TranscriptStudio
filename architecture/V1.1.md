# Transcript Studio V1.1 - Module de Prétraitement Audio

## Objectif

Ajouter un module de préparation audio avant l'envoi vers ElevenLabs afin de réduire la durée des enregistrements, diminuer la consommation de crédits, réduire le temps de transcription et conserver une qualité optimale.

## Workflow V1.1

Accueil
→ Nouvelle transcription
→ Choix du fichier audio
→ Choix : Préparer l'audio ou Transcrire directement
→ Paramètres ElevenLabs
→ Transcription

### Parcours Prétraitement

Choix du fichier audio
→ Prétraitement audio
→ Paramètres ElevenLabs
→ Transcription

## Effets disponibles

### Couper avant le curseur
Permet de supprimer le début de l'enregistrement.

### Suppression des silences
Paramètres avancés :
- seuil de détection
- durée minimale
- conserver avant/après

Valeurs par défaut reprises de TranscriptAudio.

### Accélération
Curseur de 0 à 100 %.

Correspondance :
- 0 % = x1.00
- 50 % = x1.50
- 100 % = x2.00

Code couleur :
- Vert : 0 à 50 %
- Orange : 50 à 75 %
- Rouge : 75 à 100 %
