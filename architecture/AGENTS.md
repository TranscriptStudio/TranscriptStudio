# Instructions agent - TranscriptStudio

## Règles générales

- Lire PROJECT_STATE.md avant toute modification.
- Examiner le dépôt Git avant de modifier le code.
- Ne pas modifier l'architecture sans expliquer la raison.
- Préserver la compatibilité Windows, macOS et Linux.
- Exécuter les tests concernés avant tout commit.
- Faire des commits atomiques avec des messages explicites.

## Mémoire du projet

PROJECT_STATE.md représente l'état courant du développement.

Après toute étape significative :
1. mettre à jour PROJECT_STATE.md ;
2. indiquer ce qui a été réalisé ;
3. indiquer les tests exécutés et leur résultat ;
4. indiquer les problèmes restant ouverts ;
5. indiquer la prochaine étape prévue.

Ne pas attendre la fin de la session pour mettre ce fichier à jour.
