Placez ici les Bibles (OSIS XML) — ou, plus simple,
utilisez le téléchargeur intégré : Réglages de
l'application, onglet « Bibles ».

Versions gérées (P18.5) :
    darby        Darby.osis.xml        (téléchargeable, onglet Bibles)
    darbyR       DarbyR.osis.xml       (téléchargeable, onglet Bibles)
    segond1910   Segond1910.osis.xml   (import manuel : « Charger depuis
                                         un fichier… », le fichier se
                                         télécharge sur concordance.bible)
    JND.osis.xml choix explicite hérité (prime pour un chargement
                 implicite hors étude)

La version utilisée par une étude se choisit dans les
paramètres de l'étude (« Bible de référence », défaut :
Darby révisée) ; une étude existante sans ce réglage
utilise le défaut, sans migration.

Ces fichiers ne sont pas distribués avec le dépôt
(volume et licences) : ils sont ignorés par git et ne
sont JAMAIS commités.

Sans Bible, l'application fonctionne normalement ; le
contrôle qualité des références reste local (pas
d'extrait biblique, pas d'alignement des citations).
Instructions complètes : README.md, section
« Installation des Bibles ».
